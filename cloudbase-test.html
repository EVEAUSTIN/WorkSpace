这里不会读取、上传或替换工作台的日记、笔记、药箱等现有数据。测试通过后再接入正式同步。

请通过网站 HTTPS 地址或本地开发服务器打开此页面；直接双击本地 HTML 文件可能无法正常登录。部署时请同时上传 assets 目录。

1. 登录你的应用账号

地域：上海（ap-shanghai） 只填写客户端可发布密钥；不要填写服务端 API Key、SecretKey 或数据库密码。本页不会把密钥写入 GitHub。

请在自己的设备上填写客户端密钥、应用用户名和密码。密码不会保存到页面配置中。

验证进度

  • 官方 Web SDK 加载等待加载
  • 个人账号登录尚未验证
  • 测试记录读取尚未验证
  • 测试记录写入尚未验证
  • 未登录请求检查尚未验证

两台设备怎么验证

  1. 在设备 A 打开此页面并登录，填写一句测试内容，点击“保存测试记录”。
  2. 设备 B 打开同一个网站的此页面，使用相同客户端密钥和同一应用账号登录。
  3. 确认 B 看到了 A 保存的内容，再在 B 修改并保存；回到 A 读取确认。
  4. 若两台同时修改，本页会提示版本冲突，并保留尚未保存的输入。
  5. 完成后可清理测试记录，再退出测试页登录。

本页只能验证本次连接及测试记录。完整的权限隔离还需用另一个测试账号核验，不能仅凭“登录成功”判定所有数据安全。
